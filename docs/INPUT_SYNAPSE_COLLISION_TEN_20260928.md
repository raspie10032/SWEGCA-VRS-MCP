# 원입력–활성 시냅스 충돌 10회 — 2026-09-28

## 변경된 실행 경로

사용자 확정: 원입력 → 여러 활성 시냅스 → 입력과 시냅스 충돌 → SWEGCA 판정 → 즉시 강도 갱신 → 갱신된 상태를 다음 입력/회차에 사용. 동일 경험 중복 계수 금지는 반복 검증·강도 갱신 금지가 아니다.

`InputCollision`은 입력 타입을 가정하지 않는 경험 멤버/연결 실행 경로다. 현재 실행 어댑터는 보유한 이미지 경험의 원래 기록된 태그를 읽는다. 네이티브 원경험과 전체 특징 레코드(잡음·제안 플래그·점수·DINO 포함), 원이미지와 점수 파일의 참조/해시를 보존한다. 과거의 승인/반려 행렬은 **초기 강도만** 제공하며 이번 판정 정답으로 읽지 않는다. 기존 개념 노드의 승인 목록도 입력을 거르는 데 쓰지 않는다. 새 점수 임계값·기권 선처리·강도 상한은 추가하지 않았다.

이것은 원이미지/음성/텍스트/영상의 의미를 코어가 자동 해석하는 기능의 완성을 뜻하지 않는다. 이번 검증 술어는 기록된 멤버의 존재이며 DINO 유사도 검증이나 다른 입력 타입의 실데이터 시험은 포함하지 않았다. **공통 충돌 실행 경로와 모든 입력 타입의 의미 관측 구현 완료는 별개다.**

## 이번 충돌 명제와 배선

- 명제는 **이 현재 입력이 이 연결을 지지하는가**다. 과거 태그–태그의 ‘전체 자료 어딘가에 공동 출현이 존재하는가’와 별도 문맥이다. 특정 입력의 비일치를 과거 전체 자료의 존재 증명 자체를 뒤집었다고 보고하지 않는다.
- 입력의 기록된 멤버와 해당 입력의 현재 활성 연결에서 여러 시냅스를 불러온다. 저장된 활성 여부는 강도 >= 1로 결정한다. 활성 시냅스도 반박될 수 있다.
- 직접 입력이 닿는 멤버 연결과 입력에서 함께 나타나는 멤버 쌍은 강도가 약해도 검증에 참여한다. 다른 연결에서 불러오는 경로의 활성 기준과 직접 관측의 검증 참여를 구분한다.
- 각 입력에서 멤버–입력, 멤버–멤버 작업을 함께 섞는다. 입력 순서도 회차마다 섞는다. 한 입력 안에서 같은 연결이 여러 경로로 발견돼도 한 번만 처리한다.
- 코어의 `observe_recorded_member`/`observe_member_association` → `to_outcome` → `judge_association` → `revise_association_strength`를 호출한다. 승인 ×1.01, 반려 ×0.995, 기권 유지. 결과는 즉시 반영되며 다음 입력의 활성 시냅스 집합이 바뀐다. 일반 `judge_evidence`의 통계 판정식을 바꾼 것은 아니다.
- 결과는 별도 실험 상태로 저장했다. 기존 존재 명제의 그래프나 Main을 덮어쓰지 않았다.

## 진동과 수렴 해석

사용자의 ‘진동하는 현재 분포가 이미 수렴 근처일 수 있다’는 가설을 고정점 검사와 구분한다.

- 활성 태그–태그 **개수**: 1~5회 평균 26,133.4, 6~10회 평균 26,296.6. 평균 차이는 0.6245%이며, 약 2.5만~2.7만 범위다. 빠르게 비슷한 활성 규모에 도달한 양상은 관측된다.
- 활성 **연결의 정체**: 9→10회 38,550개가 활성/비활성 상태를 바꿨고, 두 회차의 활성 태그–태그 집합 Jaccard는 0.1601이다. 같은 연결 집합으로 고정된 것은 아니다.
- 10회 모두 활성으로 남은 태그–태그 연결은 4,149개. 회차 끝에서 한 번 이상 활성인 연결은 148,347개다.
- 원시 **강도 수치**: 일부는 계속 증가한다. 이것을 전체가 유한한 고정점에 도달했다고 말할 수 없다. 반대로 원시 강도의 증가만으로 활성 규모나 정규화된 분포의 통계적 안정 가능성을 배제하지 않는다. 10회 한 시드 계열만으로 통계적 정상성이나 작은 모수의 인과효과를 확정하지 않았다.
