# VRS 재구축 — 경험 생성·유지와 기억 불러오기 경계

2026-09-28 사용자 정정이 이전 설계 문서보다 우선한다.

VRS는 시냅스로 경험을 만들고 지속적으로 유지하는 로직이다.
Déjà vu / Recall / Replay / Re-evidence는 SWEGCA로 구축한 별도 기억
불러오기 로직이다. 이 네 단계를 VRS 내부에 합치지 않는다.

## 이번 구현

`cpp/vrs/synapse.hpp`, `synapse.cpp`:

- 실제로 저장된 둘 이상의 원경험 주소와 관계 정의의 원본 주소를 묶는다.
- 구성원의 순서를 보존한다. 임의의 유사도나 무방향 이미지 쌍으로 환원하지 않는다.
- 구성원·정의의 전체 주소를 포함한 정규 바이너리 binding으로 연결 ID를 만든다.
- 근거 관측과 원문을 함께 기록하고, 해당 연결에 실제 저장된 관측만 전달한다.
- 기존 SWEGCA admission → 근거 정규화 → judge_evidence →
  revise_connection_strength 회로를 사용한다. 코어 판정식과 정책은 수정하지 않았다.
- 이전 누적 tally를 입력하지 않는다. Connection이 매 셔플마다 관측에서 다시 구성한다.
- binding 주소와 core 검증 journal head를 한 체크포인트로 취급한다.
  복구 시 둘의 연결 ID가 다르면 거부하며 journal 판정을 재계산해 확인한다.
- 외부에서 final verdict나 강도를 덮어쓰는 setter를 제공하지 않는다.
- Main 자동 병합이나 기억 불러오기 호출을 하지 않는다.

```
원경험 주소들 + 관계 정의 주소 ──→ 불변 binding ───────┐
                                                     │ 동일 연결 ID
실제 관측 + 원문 ──→ 저장 ──→ 셔플 ──→ SWEGCA 판정   │
                                          │          │
이전 시냅스 강도 ──→ SWEGCA 강도 소자 ◄─────┘          │
                             │                       │
                             └──→ 불변 갱신 journal ─┘
```

## 독립 빌드

`make vrs-synapse`로 `build/libswegca-vrs.a`를 생성한다.
`make check-synapse`는 그 라이브러리를 링크해 검사한다.

새 타깃은 Runtime, SessionRuntime, MCP transport, main graph의 기억 탐색
실행 파일을 링크하지 않는다. 단, 공용 SessionStore에는 기존 cognition metadata /
replay-position 저장용 보조 API가 아직 함께 선언·구현되어 있다. 현재 이는 저장
기반의 공유이며 네 단계 기억 알고리즘 호출은 없다. 저장 코드까지 완전히 물리적으로
분리했다고 주장하지 않는다.

## 검증 및 한계

검사는 명시적으로 합성 관측 fixture다. 시각 의미 검증이 아니다.
`taskset -c 6,7 nice -n 10 make -j2 check-synapse`: 50 checks passed.
`git diff --check`: 통과. 생성한 정적 라이브러리의 정의된 심볼에서
`swegca::vrs::Runtime::`, `swegca::vrs::SessionRuntime::`는 없음을 확인했다.
표준 4축 정책을 완화하지 않고 승인 1→1.01, 반려 1→0.995, 기권 1→1,
반복 시 원경험 개수 보존, 재시작 복구, 잘못된 binding/state 조합 거부,
잘못된 원경험 주소와 중복 구성원 거부, ENOSPC 실패 후 이전 head·강도 보존,
종료된 세션 갱신 거부를 확인한다.

실제 이미지·태그·DINO 값의 검증 배선, 자동 시냅스망 구성, 연결 간 반복 처리,
전체 경험망의 영역 분할과 병렬 처리, 종료 후 Main 통합은 이 변경으로 완료되지 않는다.
기존 이미지 저장소를 변환하거나 기권 관측을 승인으로 재기록하지 않았다.
관계 정의의 저장 주소는 그 관계의 의미를 자동으로 이해했다는 증명이 아니다.
이번 구현은 VRS 자체 시냅스의 구성·갱신·영속 복구 기반이며, 전체 재구축 완료가 아니다.

## 원입력 배선 수정의 실제 범위

`observe_raw_content_relation`을 코어에 추가하고 기존 원경험 내용 재측정 함수를
연결했다. 호출자가 계산한 `equal` 불리언 대신 원본문의 두 바이트 span을 코어에
넘긴다. NUL·잘못된 UTF-8·모든 바이트 값을 그대로 비교하며 원본은 수정하지 않는다.
기존 동일/상이 술어와 3상 판정식은 변경하지 않는다. 전체 버퍼 검사는 O(n)이며
전체 이미지 검사에 ns 시간을 달성했다고 주장하지 않는다.

검사: 원바이트 관측 소자 524 checks, 원경험 재측정 통합 검사, 기존 시냅스 50
checks 통과. 한 관측이 지지를 얻더라도 기존 4축 정책의 코어 판정은 기권일 수 있다.

이 수정은 **바이트 동일/상이 재측정에 한정**된다. `Synapse::refine`은 여전히
기존 `Connection::refine`으로 연결되며 미리 기록된 관측값을 집계한다. 임의의
원자료에서 관계 가설·검증 기준을 구성하는 회로가 생긴 것이 아니다. 이미지·태그·
DINO를 입력하여 자동 검증·시냅스 갱신하는 요청은 아직 완료되지 않았고,
6,274장에 대한 실제 새 VRS 실행도 하지 않았다. 이 한계를 숨기기 위해
파일 비교를 이미지 관계 검증으로 이름만 바꾸지 않는다.
