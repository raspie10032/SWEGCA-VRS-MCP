# 정수 3상 누적 — 2026-09-28

## 상태와 활성 기준

입력 충돌 경로는 SWEGCA가 발행한 판정에 따라 uint64 `(승인, 반려, 기권)` 중 해당 성분만 1 증가시킨다. 연결 활성은 `승인 >= 반려`, 즉 순지지 0 이상이다. 기권은 독립적으로 보존한다. 비활성 연결도 수치를 보존하며 새 입력으로 다시 검증한다. 정수 초과는 상태 변경 없이 오류 처리한다.

이 기준은 승인과 반려를 같은 1회 단위로 취급하는 새 기준이다. 과거 비대칭 곱셈(1.01 / 0.995)의 활성 집합을 수학적으로 동일하게 보존하는 변환은 아니다. 실수 결과로 과거 횟수를 역산하지 않았다. 기존 태그–이미지 및 태그–태그 원본 기록에서 연결당 최초 판정 1회를 읽어 초기화하고 새 기준으로 10회 다시 수행했다.

## 기울기

`(10회 값 - 0회 값) / 10`, 단위는 횟수/회차다. 저장 상태는 정수이며 기울기만 분석용 실수다. 선형회귀나 수렴 판정은 아니다.

- `experience-slopes.csv`: 입력 원경험별로 그 입력이 일으킨 충돌 판정을 귀속시킨 합계. 이미지 품질/신뢰도 점수가 아니다. 입력 ID는 원실험 `input-records.jsonl`과 대응한다.
- `connection-slope-histograms.json`: 개별 연결의 성분 증가 분포. 증가 0인 연결도 포함한다.
- `tag-slopes.csv`: 해당 태그에 인접한 연결 증가의 합. 태그–태그 간선은 양쪽 끝에 각각 귀속된다.
- 순지지 A−R은 분석용 투영이며 영속 상태를 단일 숫자로 대체하지 않는다.

원경험별 중앙값: 승인 1,081, 반려 6,475.85, 기권 0, 순지지 −5,414 횟수/회차. 모든 태그의 부재 검증을 포함하므로 합산 반려가 많다. 기권 0은 이번 실제 자료의 명제·관측 조건에서 나온 결과이며 기권 기능을 제거하지 않았다.
