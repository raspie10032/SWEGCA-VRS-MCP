# 관계 회상에서 일반 응답이 반박 관측보다 먼저 선택되는 결함

2026-09-27. 아래 실패는 후속 수정과 재현 검사로 해결했다. 일반 자연어 요구의
의미 적합성 전체가 해결됐다는 뜻은 아니다.

## 후속 수정

- 기존 봉인 메타데이터의 `has_input_key`와 코어
  `context_reference_eligible`을 related 조회에 적용했다. 상태/점수/문자열로
  관측 여부를 추측하지 않는다. scope와 비scope 입력 결합 관측 모두 대상이다.
- 일반 응답은 context 그래프와 원경험에 그대로 보존한다. 입력에 명시적으로
  연결된 관측의 후보 자격과 대화 관계를 구별한다. 승인/반려/기권은 모두 유지한다.
- 임시에 일반 응답만 있는 경우 자격 있는 임시 관측이 없으므로 Main을 조회한다.
  발행 세션 Main과 병합 Main에도 같은 코어 자격 판정을 적용한다.
- 복원된 선택은 봉인 원경험의 표식을 확인한다. 과거 journal에 저장된 일반
  응답을 관측으로 승격하지 않는다. 현재 임시에 새 관측이 생겼다는 이유로
  이미 기억한 Main 원경험과 당시 대조 기준점을 바꾸지 않는다.
- Runtime 2047 / Session Runtime 1366 / 실제 stdio 6706 checks 통과.
  반박 8개의 네이티브 사례를 임시/Main/재시작 경로에서 재현해 정확한 도구
  원경험 주소를 검사했다. 기권 보존, 일반 원문 접근 가능, Main fallback도 검사했다.
- VRS 설치 실행 파일과 manifest 갱신. 설정/원경험/식별자는 보존했다.
  실제 backend 초기화·도구 목록·같은 자원 그룹/공유 I/O 확인, 모델 호출 0.
  자동 관련 경험 주입 기능은 여전히 추가하지 않았다.

## 실제 재현

별도 임시 저장소와 실제 C++ VRS/호스트/프록시를 사용했다. 모델 호출 없음.

1. 같은 자연 입력 `A purpose kept in Main.`을 8회 기록한다.
2. 각 turn/start에 서버의 turn ID 응답을 기록한다.
3. 각 입력에 서로 다른 생산자의 `refute` 관측을 기록한다.
   관측 scope는 `archived requirement outcome`이다.
4. 세션을 명시적으로 종료하고 seed=7, step=100으로 Main에 병합한다.
5. 새 데스크톱 fixture 세션에서 같은 자연 입력을 보낸다.
6. 부모 Replay 뒤 기존 related 경로를 자동 호출하는 시험 구현으로
   실제 backend에 전달된 부모/자식 주소를 검사한다.

부모는 마지막 입력이었지만 자식은 그 입력의 일반 서버 응답이었다.
반박 도구 결과를 선택한다는 검사는 실패했다.

같은 블록에서 관측한 주소(격리 fixture의 주소이며 설치 저장소와 무관):

| 기록 | offset | bytes |
| --- | ---: | ---: |
| 마지막 사용자 입력 | 42464 | 542 |
| 실제 선택된 일반 서버 응답 | 44316 | 427 |
| 해당 입력의 반박 관측 | 46053 | 1040 |

원시 실패 출력은 `/tmp/swegca-auto-related-stdio.log`에서 확인했으며,
임시 fixture 저장소는 시험 종료 시 삭제됐다. 이 경로는 영속 재현 자료가 아니다.

## 코드 근거

- `ExperienceRouter::related`는 부모 원경험 digest의 context 관계를 조회한다.
- 그 관계에는 실제 관측과 일반 네이티브 응답이 함께 들어간다.
- `ExperienceRouter::select_replay`는 기존 코어 `prefer_replay`를 사용한다.
- 강도가 약화된 반박 연결보다 강도가 유지된 불충분 일반 응답이 우선할 수 있다.
  코어 선택 순서 자체는 그대로 실행됐지만, 이 후보 집합을 곧바로
  '목적을 검증하는 관측 집합'이라고 취급할 수 없다.

## 처리와 남은 구현

- 시험용 자동 전달 변경은 폐기했다. 일반 응답 전달을 목적 검증 성공으로
  간주하지 않으며, 설치본·기존 코어 순서·강도 규칙은 변경하지 않았다.
- 관측 결과가 반박이라는 이유로 임의로 우선하거나 기권 경험을 버리지 않는다.
- 다음 구현은 기록된 관계의 의미를 보존하여 실제 관측 회상과 일반 대화 연속
  회상을 구별하는 것이다. SWEGCA 코어를 통한 경로 결정, 원경험 보존,
  승인/반려/기권 모두의 회상 가능성, 재시작·Main 병합 후 관계 복원이 필요하다.
- 일반 자연어 요구 추출과 의미 적합성도 여전히 미완료다. 자동 도구 조회 하나를
  붙이는 것만으로 그 요구가 충족되지 않는다는 반증을 확보한 상태다.
