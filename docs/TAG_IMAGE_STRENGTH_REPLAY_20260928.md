## 사용자 확정 기준

- 검증은 SWEGCA의 승인/반려/기권 판정이다.
- 불러올 때는 누적 연결강도를 사용한다. 유효한 강도 >= 1만 연결 근거다.
- 1 미만의 수치와 경험도 보존하고 검증 대상으로 남긴다.
- 다른 근거로 강화되어 1 이상이 되면 다시 연결 근거가 된다.
- 동일 경험의 재전달은 강화 횟수를 늘리지 않는다.

## 구현 범위

관측 커널은 `PredicateObservation {valid, holds}`를 반환한다. 공통 `to_outcome`만 invalid→insufficient, true→support, false→refute를 수행한다. 내용 비교 및 태그 소속 관측과 호출부를 함께 변경했다.

태그–이미지 실행의 판정 함수는 기존 SWEGCA `judge_association`이다. `judge_evidence`의 표본·다양성 기준을 변경하거나 두 함수를 동일하다고 취급하지 않았다. 이번 사용자 정정은 검증 판정과 조회 강도 기준의 구분이다. 기존 일반 `judge_evidence` 판정식은 그대로다.

공통 `connection_evidence_eligible`이 유한한 강도 >= 1을 검사한다. 공통 개념의 조회 연결과 이미지 연상 소비자가 최신 승인 여부 대신 이 조건을 사용한다. 기존 `ConnectionStrengthResult`와 `AssociationStrength`도 같은 조건을 사용한다.

태그–이미지 실행기에 `[PREVIOUS]`를 추가했다. 같은 원경험 그래프와 관측 행렬임을 확인하고 네이티브 블록을 인증해 이전 강도를 읽는다. 동일 근거는 재측정·재판정하지만 강도를 재곱하지 않는다. 약한 행도 모두 기록한다. 이 옵션은 동일 입력의 재실행용이며, 서로 다른 그래프의 상태를 임의로 연결하지 않고 거부한다.
