# 셔플 결과와 SWEGCA 입력의 연결 정의 확인

2026-09-26. 구현 기준 커밋 `0f41457`, 브랜치 `codex/vrs-completion-20260926`.

## 확정된 사용자 지시

블록 안의 경험을 섞고, 그 셔플값을 SWEGCA로 검증해 승인/반려/기권을
연결 강화/약화/유지에 대응한다. 기존 누적값을 읽는 방식으로 대신하지 않는다.
임의의 외부 판정 로직을 만들거나 가져오지 않는다.

## 현재 근거와 누락된 연결

1. 보존된 C++ 코어의 `EvidenceTally`는 축별 지지·반박값, 출처·맥락 다양성,
   최근 결과, 개정을 입력받는다. `verify_experience`와 `verify_connection`은
   이 입력을 호출자가 만든다는 계약이다.
2. 사용자 원본 `SWEGCA-Architecture@5901a5a`의 `EvidenceObservation`은 이미
   지정된 `axis`와 `outcome`을 받는다. 원본 집계는 같은 출처·맥락의 지지/반박
   비율을 계산하며, 셔플된 VRS 상태값에서 `axis/outcome`을 생성하지 않는다.
3. 원본 `tools/organize_rozephine_mixed_experience_connections_hybrid.py`의
   `refine_vrs`는 셔플된 연결을 따라 상태값을 갱신하고 별도 안정성을 계산한다.
   확인한 함수에는 SWEGCA 증거 집계로 연결하는 호출이 없다.

따라서 비어 있는 부분은 **셔플된 경험에서 무엇을 검증하고 그 값을 어떤 SWEGCA 입력으로
전달하는가**다. 현재 집계형 인터페이스가 사용자가 의도한 모든 코어 입력을 표현한다고
단정하지 않는다. 다른 코어 입력이 의도됐다면 그 정의를 근거로 인터페이스를 구성해야 한다.

이 정의를 알고 있는 원본 문서·함수, 또는 한 건의 셔플 입력과 기대 코어 입력 예시가 필요하다.
사용자에게 보낸 확인 요청은 아직 답변을 받지 못했다.

## 그동안 완료한 독립 작업

- `b41dfac`: 코어 판정과 VRS 변화 방향의 일관성, 원본 강도 연산 연결.
- `4a4a23d`: 원경험 본문·출처의 블록 저장, 주소 선택 읽기, 불완전 기록 보존.
- `0f41457`: VRS 공유 메모리 예산과 읽기 버퍼의 합산 계수.

위 작업들은 변환 규칙을 임의로 정하지 않고 진행할 수 있었다. 실제 VRS 경험 구성,
판정 대상과 연결의 결합, 회상·재검증에는 위 입력 정의가 필요하다. 구조 명칭이나
외곽 코드만 늘려 이 경로의 완성을 대신하지 않는다.

## 전체 목표의 현재 증거

| 요구 | 현재 증거·상태 |
| --- | --- |
| SWEGCA 기반 3상 판정·강도 연산 | 코어 호출과 불변 결과, 검사 통과. 실제 경험에서 시작하는 연결은 미완료 |
| 코어 공정 ns 시간대 | 기록된 CPU 검사에서 강도 약 1.33ns, 4축 판정+강도 약 50.49ns. 입력 준비 후 호출 평균 |
| 실제 셔플값 검증·해당 연결 반영 | 입력 계약 확인이 필요하며 미구현 |
| 사용자 입력 즉시 Déjà vu→Recall, 1ms 미만 | 입력 훅과 경험 탐색 경로가 없어 미구현·미검증 |
| 선택 Replay와 충돌 시 Re-evidence | 주소로 본문 한 건을 읽는 물리 구성요소만 구현. 선택·대조·재검증 미구현 |
| 세션 전체의 실시간 임시 경험 | 원문 보존 구성요소만 구현. 입력 수집 및 경험 처리 미구현 |
| 임시 우선·메인 대체 조회, 종료 후 병합 | 상위 경험 구조와 세션 스케줄러 미구현 |
| 분할·연결선·병렬 처리 | 단일 블록 경계와 별도 파일 소유 기반만 구현. 경험 그래프와 처리기 미구현 |
| 4GB·5Gbps·500GB 조건과 확장 설정 | 공유 할당 계수 및 설정 가능한 한도만 구현. 전체 RSS·디스크·I/O 운용 미검증 |
| Main 소유 및 출처·불확실성·반증 보존 | 원문과 출처를 보존하는 구성요소 있음. 완성된 Main 경험 경로 미구현 |

| 장기 모델 평가 전 기능 완결 | 장기 모델 평가를 실행하지 않음 |
| Claude 중지, Palworld 자원 보존, Actions 미실행 | Claude 통신 없음, 빌드 2작업·경쟁 검사 2스레드, Palworld 실행 유지, 로컬 커밋만 수행 |

전체 목표는 미완료다. 같은 입력 계약 확인 요청은 최초 구현 턴과 이후 두 차례의
구현 턴에 걸쳐 유지됐으며, 현재 소스 대조로 다시 확인했다. 장기목표를 확인 대기
상태로 전환하며, 위 정의가 제공되면 남은 원래 범위로 계속한다.
