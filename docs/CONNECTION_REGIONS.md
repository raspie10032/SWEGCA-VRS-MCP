# Main 연결 디렉터리의 주소 지역 분할

MainGraph의 단일 `map<connection, Entry>`를 `ConnectionRegions<Entry>`로 교체했다.
이것은 실제 Main 조회·병합·Replay가 사용하는 연결 디렉터리 변경이다. 기본 지역
한도는 연결 256개이며 MainGraph 생성자가 다른 양의 한도를 받을 수 있다. 크기는
VRS 계층이 정하고, 코어에는 한도와 현재 고유 연결 수를 전달한다.

## 판정과 보존

- 코어 `region_partition_end`가 각 지역의 끝 경계를 결정한다. 범위·한도 검증과
  오버플로 없는 경계 계산만 수행한다. 연결 digest 순서로 주소 영역을 나눈다.
- 주소 인접성은 의미 유사성이나 지지/반박 관측이 아니다. 분할은 연결 강도를
  바꾸거나 경험을 새 표본으로 세지 않는다.
- 실제 경험 셔플·SWEGCA 검증·3상 강도 갱신은 기존 연결별 준비 경로 그대로다.
  원경험 주소, 출처 범위, 봉인된 관측과 검증 보고서가 같은 Entry 안에 유지된다.
- 입력 조회는 지역 경계 디렉터리에서 한 지역을 선택하고 그 지역에서 연결을 찾는다.
  원경험 내용 읽기나 병합 작업을 이 조회 앞에 넣지 않았다.

## 병합·실패·복구

준비 단계에서 이미 정렬된 기존·신규 키를 순차 병합하며 고유 개수를 세고,
두 번째 순회에서 코어가 지정한 분할 경계의 빈 지역 노드만 할당한다. 전체 키의
복사 벡터나 재정렬은 만들지 않는다. 이 단계는 공개 그래프를 변경하지 않는다. 준비 중 할당 실패는
기존 지역·연결·세대·원경험을 유지한다.

Main이 기존 세대 확인과 영속 병합 기록을 마친 뒤에는 같은 PMR 할당자를 사용하는
map 노드를 이동한다. 지역 경계와 연결 노드를 옮기는 확정 단계에는 추가 할당이나
파일 I/O가 없다. 수정되지 않은 연결의 주소는 지역을 이동해도 유지된다. 업데이트된
연결이 교체되는 기존 규칙은 유지한다.

지역 디렉터리는 기존의 검증된 병합 이력에서 재구성되는 주소 구조다. 이를 별도
판정 이력으로 기록하지 않는다. 저장 형식·원경험·병합 결과 digest는 바뀌지 않았다.
Main 재시작 시 같은 셔플 검증을 재생하고 지역 디렉터리를 다시 만든다.

## 검증

- 지역 단위 검사 234개: 범위/오버플로, 신규 분할, 여러 지역의 갱신, 실제 노드
  주소 보존, 할당 실패 후 기존 상태 유지, 확정 중 할당 금지.
- Main 그래프 검사 3,915개: 지역 한도 1로 분할을 강제한 실제 경험 병합,
  756개 할당 실패 지점과 기존 셔플·강도·원경험 보존 검증.
- 영속 Main 검사 852개: 257개 연결을 두 지역으로 분할하고 재시작 후 모든
  연결의 원경험을 Replay하여 원래 주소와 대조하는 검사 포함.
- MCP 프로세스 검사 2,213개 통과. CPU 6·7, 컴파일 최대 2개로 실행했다.
- 새 분할 커널의 단독 네이티브 마이크로벤치: CPU 6에서 2,000,000회 호출,
  평균 **5.306ns/call**. 함수 호출 및 반복문 비용을 포함하는 한 번의 측정이며
  실제 입력→Recall 지연·최악 지연·전체 SWEGCA 성능을 증명하는 수치가 아니다.

## 아직 남은 범위

이 구현은 **연결 주소 지역 분할**이다. 의미적 지역 탐색, 공유 경험의 지역 간 포털,
지역의 디스크 퇴거/적재는 아직 구현하지 않았다. 연결 Entry와 경험 색인은 여전히
전체 규모에 비례해 메모리에 상주한다. 한 지역의 연결 수 제한은 그 지역의 바이트
메모리 제한도, 임의 크기 Main의 4GB 운용 증거도 아니다. 특히 경험이 많은 단일
연결을 더 나누는 문제는 별도로 남는다. 기존 그래프 완결 요구를 이 변경으로
완료 처리하지 않는다.


## 분할 준비 메모리 보강

32,768개 신규 연결에서 분할 준비에 쓸 예산을 32KiB만 남기고 128개 지역을
발행하는 검사를 통과했다. 기존 방식의 키 벡터는 digest 본문만 1MiB였으며
성장 중 이전/신규 버퍼는 별도였다. 현재 추가 할당은 지역 노드와 교체 지역 목록이다.
이미 존재하는 연결 Entry·pending·경험 메타데이터는 이 32KiB에 포함되지 않는다.

지역 검사 66,255개, Main 그래프 검사 4,700개 통과. 913개 Main 할당 실패 지점,
교체/신규 키의 교차 순서, 중복 키의 단일 계수, 변경되지 않은 연결 주소,
발행 중 추가 할당 금지를 확인했다. 판정과 저장 형식은 변경하지 않았다.
이 보강은 분할 준비의 일시 메모리 감소이며 전체 Main 상주 문제의 해결은 아니다.
